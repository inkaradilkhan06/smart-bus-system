# smart-bus-system

AI FacePay Bus — AI камера арқылы жолаушының жүзін танып,
автобус жолақысын автоматты түрде төлеуге арналған ақпараттық жүйе.

Жолаушы автобусқа кірген кезде AI камера оның жүзін анықтайды.
Жүйе Face ID профилін табады және профильге тіркелген төлем
құралынан жолақыны автоматты түрде есептен шығарады.

Жолаушыға QR-код сканерлеу, карта немесе телефонды
валидаторға басу қажет емес.
