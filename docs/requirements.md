# AI FacePay Bus — System Requirements

## Functional Requirements

1. AI камера автобусқа кірген жолаушының жүзін анықтауы керек.
2. Жүйе жолаушының жүзін Face ID профилімен сәйкестендіруі керек.
3. Жүйе профильге тіркелген төлем құралын автоматты түрде анықтауы керек.
4. Жолақы автоматты түрде есептен шығарылуы керек.
5. Төлем нәтижесі дерекқорда сақталуы керек.
6. Төлем сәтті болса, жүйе электронды чек қалыптастыруы керек.
7. Төлем сәтсіз болса, жолаушыға хабарлама жіберілуі керек.

## Non-Functional Requirements

1. Жүйе жылдам жұмыс істеуі керек.
2. Жолаушының Face ID және төлем деректері қорғалуы керек.
3. Жүйе автобустың жұмыс уақытында тұрақты жұмыс істеуі керек.
4. Биометриялық деректер қауіпсіз сақталуы керек.
