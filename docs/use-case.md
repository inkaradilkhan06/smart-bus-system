# Smart Bus — Use Case

## Actor-лар

- Жолаушы
- AI камера
- Әкімші
- Жүргізуші
- Төлем жүйесі
- Айыппұл жүйесі

## Негізгі Use Case-тер

1. Автобусқа кіру
2. Жолақыны төлеу
3. QR арқылы төлеу
4. NFC арқылы төлеу
5. Face ID арқылы төлеу
6. «Оңай» картасымен төлеу
7. Жолаушыны анықтау
8. Жолаушылар санын анықтау
9. Толтырылу деңгейін анықтау
10. Түстік индикаторды көрсету
11. Төлемді тексеру
12. Айыппұл рәсімдеуге сұраныс жіберу
13. Статистиканы қарау
14. Маршрутты басқару

## Негізгі сценарий

1. Жолаушы автобусқа кіреді.
2. AI камера жолаушыны анықтайды.
3. Жүйе жолаушылар санын жаңартады.
4. Автобустың толтырылу деңгейі анықталады.
5. Жүйе жасыл, сары немесе қызыл индикатор көрсетеді.
6. Жолаушы жолақысын төлейді.
7. Жүйе төлемді тексереді.
8. Төлем сәтті болса, төлем расталады.
9. Төлем жасалмаса, айыппұл рәсімдеуге сұраныс жіберіледі.
