# AI FacePay Bus — Use Case

## Actor
Жолаушы

## Use Case
Автобус жолақысын AI арқылы автоматты төлеу

## Бастапқы шарт
Жолаушы Face ID профилін және төлем құралын алдын ала тіркеген.

## Негізгі сценарий

1. Жолаушы автобусқа кіреді.
2. AI камера жолаушының жүзін анықтайды.
3. Жүйе Face ID профилін табады.
4. Жүйе тіркелген төлем құралын тексереді.
5. Жолақы автоматты түрде есептен шығарылады.
6. Төлем сәтті болса — «Төленді» статусы тіркеледі.
7. Электронды чек сақталады.

## Альтернативті сценарий

Егер төлем орындалмаса:
1. Жүйе «Төленбеді» статусын тіркейді.
2. Жолаушыға төлем сәтсіз болғаны туралы хабарлама жібереді.

## Нәтиже
Жолаушы QR-код, карта немесе телефон қолданбай жолақыны автоматты түрде төлейді.
